# Лицензия звуков прототипа

Файлы public/sounds/kick.wav, snare.wav, hat.wav созданы кодом scripts/generate-sounds.mjs специально для SongKit. Чужие записи и семплы не использованы. Генерация детерминирована, sample rate 22050 Hz, PCM 16-bit mono.

Эти три звуковых файла предоставляются по CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/legalcode

Синтезированные one-shot звуки временные: акустический банк требует отдельного выбора и проверки лицензии. Лицензия всего приложения этим документом не определяется.

Основные runtime-зависимости: React/React DOM — MIT, Tone.js — MIT, Workbox — MIT. Точные версии закреплены в package-lock.json. Тексты лицензий установленных пакетов находятся в node_modules соответствующих пакетов. При добавлении ресурсов обновлять реестр; запрещены семплы с разрешением только на готовые музыкальные произведения без права распространения самих файлов.
