# Барабанная партитура SongKit

«Ноты» открывают просмотр текущей партии. Смена такта в окне партитуры не перемещает сетку. При закрытии фокус возвращается к кнопке. Партитура строится из подтверждённых ударов, поэтому предпросмотр брейка не меняет записанную партию.

| Инструмент       | Позиция от центральной линии в полушагах | Головка |
| ---------------- | ---------------------------------------- | ------- |
| Бочка            | −3                                       | Овал    |
| Напольный том    | −1                                       | Овал    |
| Малый            | +1                                       | Овал    |
| Средний том      | +2                                       | Овал    |
| Высокий том      | +3                                       | Овал    |
| Райд             | +4                                       | ×       |
| Закрытый хай-хэт | +5                                       | ×       |
| Крэш 1           | +6                                       | ×       |
| Крэш 2           | +7                                       | ×       |

Положение остаётся фиксированным при удалении или добавлении других инструментов. Скобки относятся к головке тихого удара. Горизонтальный акцент обозначен знаком `>`. Когда акцент относится лишь к части аккорда, под станом указаны доля и конкретные инструменты. SongKit использует верхний голос для рук и нижний для бочки.

Доли 4/4 разбиты по 960 ticks. Позиции ударов и пауз определяются внутри каждой доли. Партия хранит атаки, поэтому длительности выбираются для читаемого заполнения долей без выдуманных удержаний. Одновременные удары одного голоса собираются в аккорд. Когда в голосе на одной доле смешаны прямые и триольные позиции, позиции 0 и 480 принадлежат прямому слою, а несовпадающие триольные позиции показываются в дополнительном слое с обратным направлением штилей. Совпадающая с ударом пауза вспомогательного слоя скрыта. Удары сохраняют точную позицию. В пустом такте одна пауза.

Рендерер VexFlow загружается при открытии окна. Прекеш включает его модуль, шрифт Bravura и лицензию шрифта. Bravura WOFF2 поставляется побайтово из `@vexflow-fonts/bravura@1.0.2`.

Источники: [Norman Weinberg, Guidelines for Drumset Notation](https://www.drumnotes.com/docs/notation.pdf) · [MusicXML, Percussion](https://www.w3.org/2021/06/musicxml40/tutorial/percussion/) · [LilyPond, Writing rhythms](https://lilypond.org/doc/v2.26/Documentation/notation/writing-rhythms.html) · [VexFlow](https://github.com/vexflow/vexflow) · [Bravura](https://github.com/steinbergmedia/bravura).
