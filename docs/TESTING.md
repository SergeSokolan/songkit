# Проверка SongKit

## Автоматические проверки

npm run check — форматирование, ESLint, TypeScript strict, FSD/циклы, Vitest с coverage ядра >=90% statements/branches/functions/lines, production build и ограничения размеров.

Unit/property: метр и 32-е, границы, изменение/перенос, удаление/resize, undo/redo, сила, безопасный разбор файлов и черновиков. Scheduler: точные timestamps, единственный старт, loop, живые правки, tempo, остановка/возобновление и отбрасывание фонового backlog. Storage: round-trip и сохранность при повреждении. MIDI: независимый decoder. UI: касания и выбор силы.

Браузеры: npm run test:e2e после production build с BASE_PATH=/songkit/. Chromium и WebKit mobile: редактирование, ghost, undo, сохранение/reload, аудиостарт, офлайн reload и экспорт, сокращение фразы, неверный импорт, ширина 390px. Playwright сам запускает preview на 127.0.0.1:4173.

Браузеры установить: npx playwright install chromium webkit (в Linux CI — --with-deps). На Windows можно указать PLAYWRIGHT_BROWSERS_PATH, если кеш по умолчанию недоступен.

## Ручная приёмка на iPhone 13

Записать версию iOS, Safari, commit и способ запуска. Открыть HTTPS-адрес, дождаться «Доступно офлайн», добавить на главный экран через меню Safari.

1. Воспроизвести пример и редактировать 10 минут: без слышимых пропусков, повторов и зависаний.
2. Новая партия → 1/32 → тихий малый, акцент бочки; переключить сетку туда/обратно; проверить сохранность.
3. Перенести удар через меню; прокрутить мелкую сетку без случайной правки; проверить портрет и альбом.
4. Добавить такты, сократить с предупреждением, отменить. Изменить темп на ходу.
5. Свернуть приложение и заблокировать экран. Вернуться: ноты и редактор сохранены, звук остановлен. Reload и закрытие/открытие также восстанавливают черновик.
6. Включить авиарежим после прогрева. Перезапустить приложение, проиграть, изменить, экспортировать MIDI/JSON в Files. Открыть JSON повторно; MIDI проверить в музыкальной программе.
7. Повторить в Safari и режиме Home Screen. Bluetooth оценивать отдельно от встроенного динамика.
8. Проверить p95 визуального отклика <100 мс инструментальным замером; отсутствие лагов не объявлять только по ощущениям или desktop WebKit.

Цель startup JS gzip <=300 KiB; полный пакет <=8 MiB. Измерения размера автоматизированы, замеры iPhone ожидаются. Ошибки устройства документировать с шагами воспроизведения и regression test.
