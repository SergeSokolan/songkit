# Проверка SongKit 0.4.2 на телефоне

Проверять на https://sergesokolan.github.io/songkit/ сначала в установленной PWA, затем основные сценарии в Safari. Записать модель телефона, версию ОС и режим (PWA/Safari).

- [ ] Перед изменением партии скачать резервную копию кнопкой «Проект». Дождаться «Черновик на устройстве».
- [ ] Внизу страницы видна версия v0.4.2. Если старая: открыть приложение с интернетом, дать загрузиться обновлению, полностью закрыть PWA и все вкладки SongKit, открыть снова. Не удалять PWA и данные сайта. Кнопка обновления ещё в бэклоге #28.
- [ ] Темп (#20): стереть значение, последовательно набрать 40, 100, 239, 240. Цифры не сбрасываются. Выход из основного поля подтверждает значение. Пустое/39/241 возвращает прошлое значение с подсказкой.
- [ ] BPM → точный ввод: набрать 239, нажать «Готово» — применяется 239. Ввести другое значение и «Отмена» — темп прежний. Неверное значение не закрывает окно, его можно исправить. Клавиатура не мешает кнопкам.
- [ ] Динамика (#21): «Изменить / перенести удар» → клетка → тихий/акцент. Панель закрывается, меняется нужный удар. Проверить закрытие крестиком и касанием фона; затем перенос и удаление, Undo. При VoiceOver фокус остаётся внутри открытого окна и после закрытия возвращается к клетке. Tab/Shift+Tab/Escape — только если есть внешняя клавиатура; иначе отметить «не проверено».
- [ ] Брейки (#23): раскрыть библиотеку и «Дополнительно: генератор и произвольный участок». Выбрать «Малый восьмыми»: одна пара «Применить брейк» / «Отменить предпросмотр» в библиотеке. Выбрать предложение генератора: пара переходит в его раздел. Отмена не меняет партию; применение отменяется одним Undo.
- [ ] Триоли (#25): портрет → металл → ¼ такта → разрешить недостающие дорожки → «4 руками + 2 бочкой». Сетка 1/16T, все шесть подсвеченных клеток бочки видны на ширине 390 CSS px, если помещаются. На меньшем экране начало участка видно и остаток доступен прокруткой. Отмена возвращает прежнюю сетку/прокрутку. Повторить с «2 руками + 2 бочкой» (1/16).
- [ ] Счётчик (#24): после сохранения своей партии нажать «Новая партия». Для 0/1/2/5 ударов показаны «0 ударов», «1 удар», «2 удара», «5 ударов»; при желании проверить 11/21/22.
- [ ] Звук/транспорт (#9–#10): Play/Pause работают и сверху, и рядом с сеткой. После паузы продолжение с прежнего места. Добавить дорожки и прокрутить — управление остаётся доступным. Свернуть приложение: звук прекращается, возврат сам его не запускает. Проверить портрет/альбом.
- [ ] Редактирование (#13–#16): касания пусто → обычный → тихий → пусто; прокрутка не ставит ноты. Томы сверху 1 → 2 → 3, бочка снизу. Переключение 1/16 ↔ 1/16T не удаляет ноты. Undo/Redo работают.
- [ ] Сохранность/офлайн: добавить ноту и сменить темп, дождаться «Черновик на устройстве» и «Доступно офлайн». Закрыть и открыть PWA — всё сохранилось. В авиарежиме повторно открыть, отредактировать и воспроизвести. Вернуть сеть. Сохранить JSON и MIDI; повторное открытие JSON восстанавливает партию.
- [ ] Музыкальная оценка (#11–#12, #17): прослушать базовый ритм → брейк → ритм при 60/100 BPM, металл также 140 BPM. Нет неожиданных пауз/обрыва, рисунок и динамика понятны. Применение брейка меняет только выбранный участок. Отметить конкретные названия неудачных вариантов. Для закрытия каталожных задач нужен проход всего согласованного каталога, одной карточки недостаточно.

Для каждого пункта прислать OK / ошибка / не проверено. Для ошибки: пункт, шаги, что ожидалось и что получилось, режим PWA/Safari; по возможности снимок или запись экрана. Этот чеклист не означает, что ручные проверки уже выполнены.
