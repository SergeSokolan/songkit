# Каталог базовых ритмов v1

Дата: 2026-10-27. 15 оригинальных учебных адаптаций SongKit, CC0. Не транскрипции; жанры не исключительные. Все примеры — законченный такт 4/4, 3840 ticks, PPQ=960. Повтор только целыми тактами. tick@velocity; отсутствующие позиции — паузы. Счёт 1–2–3–4; 960 ticks на долю. Уровень ниже учебный, не оценка исполнительской техники. Рекомендуемые темпы сравнения: 60 и 100 BPM, металл дополнительно 140.

Источники семейства: [рок и backbeat](https://www.drumeo.com/beat/rock-drumming-101/), [двойная бочка](https://www.drumeo.com/beat/a-drummers-guide-to-metal/), [ghost notes](https://www.drumeo.com/beat/ghost-notes/), [фанк с тихими ударами](https://content.alfred.com/catpages/00-39301.pdf), [линейность](https://dddrums.com/4-must-learn-linear-fills-drum-lesson/), [джазовый ride](https://www.halleonard.com/dealers/bin/PromoBandOrchestraEejazzsampler.pdf), [swing/comping](https://www.drumeo.com/drumshop/jazz-drumming-system). Изучение не подтверждает популярность каждой нашей адаптации.

Пользователь подтвердил в чате 2026-10-27: обычный свинг — long/short (0/640), обратный — short/long (0/320) внутри четверти. В ride дополнительные ноты стоят только после второй и четвёртой доли, а не после каждой. Малый/бочка имеют свои ticks. Обратный вариант — учебный эксперимент по согласованному смыслу, не джазовый стандарт. 2:1 не моделирует все темпы и живое исполнение. Слуховое сравнение и проверка связки грув → брейк → грув человеком ещё не выполнены.
