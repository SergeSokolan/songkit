# Каталог брейков v1

Дата: 2026-10-27. 33 оригинальные учебные адаптации SongKit, CC0; это не транскрипции источников. Жанр обозначает применение, а не исключительную принадлежность. Чужие записи и нотные файлы не включены.

Источники проверены через первичные страницы и поисковый индекс 2026-10-27. Native Instruments доступен по blog.native-instruments.com; старый адрес из бэклога открывается нестабильно. Taso доступен через индекс. DD Drums подтверждает группировки RLKK/RLRLKK, Taso — RLK и различие аппликатуры/инструмента. Наша триольная оркестровка и завершения самостоятельные. Фанковые ответы — авторские упражнения по принципам линейности и ghost, а не точные примеры авторов.

Счёт: 1–2–3–4; восьмые «1 и», шестнадцатые «1 е и а», триоли «1 три оль», секстоли — шесть равных частей четверти. PPQ=960, 4/4=3840. Формат ниже: относительный tick@velocity; интервалы без событий — паузы. Конец исключён. S=малый, H=хэт, K=бочка, Т1/2/3=томы; R/L=руки. Обычный=80, тихий=35. Рекомендуется сравнить при 60 и 100 BPM (для металла дополнительно 140); темп пользователя не меняется.

Каждая карточка имеет собственные события; короткий pop-pickup в длинном участке содержит начальную паузу. RLKK повторяется целыми группами в шестнадцатых; RLK — триолями; RLRLKK — секстолями. Нет обрезанных групп и события на следующем такте.

Слуховая валидация человеком ещё не выполнена: каталог технически проверен, музыкальная приёмка остаётся открытой. Проверить грув → брейк → грув на медленном и рабочем темпе.
