# SongKit 0.2 — отчёт

> Документ описывает историческую версию0.2. Актуальные UI,порядок томов,сетки и результаты — [текущий отчёт](BACKLOG-2026-10-27.md),[спецификация](SPEC.md). Не использовать этот отчёт как описание0.4.

Дата: 2026-10-25.

## Новые возможности

Базовые хай-хэт, малый и бочка отображаются сверху вниз, бочка всегда внизу. Через «Добавить инструмент» доступны томы 1–3, райд, крэши 1–2. Полный порядок сверху вниз: крэш 2, крэш 1, райд, хай-хэт, том 3, том 2, том 1, малый, бочка. Порядок не зависит от последовательности добавления.

У каждой дорожки собственный синтезированный звук, GM-нота и три уровня силы. Добавление отменяется общей историей. Набор сохраняется в JSON и локальном черновике, работает при редактировании на ходу и офлайн. Pattern v2 автоматически восстанавливает старые проекты и черновики v1.

## Исправление CI

Исходный CI проходил сборку и Chromium, но WebKit зависал при загрузке аудиобиблиотеки. Tone.js использовался лишь для аудиоконтекста и заменён нативным Web Audio: контекст создаётся только после жеста пользователя. Регрессионная проверка подтверждает отсутствие контекстов при загрузке редактора. Исправление отдельно прошло GitHub Actions: https://github.com/SergeSokolan/songkit/actions/runs/40216234860.

GitHub Actions закреплены проверенными SHA официальных actions. Pull request проверяется один раз, main повторно проверяется перед публикацией. Deploy зависит от verify и публикует тот же проверенный артефакт, без повторной сборки. Пользователь разрешил включение GitHub Pages; итоговый статус публикации проверяется отдельно по deployment и HTTPS.

## Проверено локально

- 99 тестов логики, UI, звуков и миграций; 5 тестов FSD-проверяющего скрипта.
- Покрытие доменного ядра: 100% statements, branches, functions, lines.
- 18 браузерных сценариев в Chromium и WebKit прошли: добавление всех инструментов, порядок и отмена, старый JSON, восстановление, офлайн-звуки, MIDI/JSON, изменение во время игры.
- Форматирование, ESLint, TypeScript strict, FSD/циклы, production build и размерные ограничения проходят.
- JavaScript gzip ~77.6 KiB; полный офлайн-пакет ~668 KiB, включая все звуки и лицензии.
- Отдельные звуки проверены как непустые и различные PCM WAV; MIDI разобран независимым парсером.

Предыдущая отмена скачивания Chromium была ограничением изолированного запуска: при обычных правах Windows скачивание и проверка содержимого проходят. Полная версия проверяется CI в PR перед merge.

## Практические ограничения

Настоящий iPhone 13, текущая iOS, 10-минутная сессия и инструментальный p95 ещё требуют ручной приёмки. WebKit Windows не содержит AudioContext; его проверки подтверждают интерфейс и корректное сообщение, не звук Safari. Звуки пока синтезированные, акустический банк остаётся отдельным улучшением.

Нотация, брейки, другие размеры и артикуляции, MP3/MusicXML находятся в следующих этапах.

## Обновление 0.2.1: iOS-аудио и ссылка GitHub

Добавлена прямая ссылка на исходники и номер версии в футере. Для iPhone добавлена видимая подсказка при отсутствии звука. При пользовательском запуске опциональный Audio Session API получает type=playback; неподдерживаемый API не блокирует обычное воспроизведение. Зависший resume больше не оставляет кнопку загрузки навсегда, восстановление пересоздаёт контекст и запускает проверочные звуки без изменения партии.

Локально проходят 111 тестов, пять проверок FSD и 22 браузерных сценария. Физический переключатель iPhone нельзя эмулировать этими тестами: после публикации требуется повторная проверка пользователем на устройстве. Реализация не определяет mute-состояние и не утверждает, что тестовый сигнал был услышан.

## Версия 0.3.0 — задачи #6 и #7

Реализованы шесть оригинальных библиотечных брейков rock/pop/funk и локальный генератор v1. Выбор участка до 1/32, дорожки замены, явное разрешение новых инструментов, недеструктивный предпросмотр с одним аудиотранспортом и атомарное применение с Undo/Redo. Предпросмотр имеет отдельный вид редактора и не записывается в черновик; экспорт читает подтверждённую модель.

Мобильный темп: −/+ по 1 BPM, удержание 450/100 мс, барабан с подтверждением/отменой, ручной ввод и управление клавиатурой. Решения, каталог, ограничения и источники задокументированы в FILLS.md и MOBILE-TEMPO-UX.md. Новых зависимостей нет.

Локально: check, production BASE_PATH=/songkit/, 123 unit/integration/UI tests, 5 self-tests архитектурной проверки, 28 полных E2E + 2 новых E2E восстановления предпросмотра прошли. Проверяемые модели: 100% lines/functions, 97.29% branches; модель партии 100%. Chromium mobile emulation: ширина страницы 390/390 CSS px, просмотрены скриншоты барабана и брейков. Размер startup JS gzip около 83 KiB, весь offline bundle около 689 KiB.

Физический iPhone 13, VoiceOver, переключатель Silent и музыкальная оценка каталога не проверены на устройстве. Не считать эмуляцию WebKit подтверждением этих пунктов. CI и публикация подтверждаются отдельно ссылками на PR и успешный workflow.
