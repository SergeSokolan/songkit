# Отчёт этапов A/B — 2026-10-25

## Сделано

FSD-каркас и автоматический контроль импортов/циклов, TypeScript strict, фиксированные зависимости и lockfile. Музыкальное ядро PPQ=960, 4/4, 1–4 такта, три инструмента, деления до 1/32, velocity, перенос, undo/redo. Аудиопланировщик с живыми правками и остановкой в фоне. Локальное восстановление и офлайн PWA. MIDI и JSON, строгий безопасный импорт. Оригинальные синтезированные звуки, лицензии runtime-зависимостей. CI и выключенный до согласования CD.

## Проверено

- npm run check: форматирование, lint, типы, FSD, тесты, coverage, production build и размеры проходят.
- 78 тестов логики/компонентов прошли.
- 5 тестов самого FSD-проверяющего скрипта проходят.
- Доменное ядро: 100% statements/branches/functions/lines на проверенном прогоне.
- 11 из 12 браузерных сценариев прошли: оба браузера проверили редактирование, восстановление, офлайн, длину фразы и мобильную ширину. Chromium проверил аудиостарт и правки; WebKit Windows не содержит AudioContext и проверил понятное сообщение об этом.

Причина в этом окружении пока не установлена. Строгий тест оставлен включённым и должен пройти в GitHub CI; зелёный CI не заявлен.
- Размер с полными текстами лицензий: стартовый JS gzip ~133 KiB, весь пакет ~582 KiB. Проверяется скриптом budget.
- Визуально просмотрены desktop и mobile скриншоты; горизонтального переполнения страницы 390px нет. Мелкая сетка прокручивается внутри редактора.

## Ограничения

Реальный iPhone 13, текущая iOS, 10-минутное прослушивание и p95 отклика ещё не проверены. Тестовый WebKit Windows не является проверкой звука Safari. Звуки временные синтезированные, не финальная акустическая установка. Отдельное увеличение доли пока заменено крупными клетками с прокруткой.

Нотный стан, остальные размеры/инструменты, брейки, MP3/MusicXML — следующие этапы по SPEC. Не выдавать их за готовые функции.

GitHub CLI из среды агента возвращает HTTP 401, хотя пользователь авторизован в собственном PowerShell. Git push через настроенный credential helper дополнительно блокируется запуском MSYS shell в среде агента. Изменения сохраняются локально в рабочей ветке; отправку и GitHub CI не считать выполненными до подтверждения удалённого коммита.
