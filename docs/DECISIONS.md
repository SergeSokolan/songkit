# Принятые решения

Актуальная редакция 0.4.0 от 2026-10-28. Первоначальные решения и отменённый вариант кнопки сброса сохранены в [истории](history/DECISIONS-2026-10-27.md).

1. Объём:4/4,1–4 такта,3 базовые и 6 добавляемых дорожек. Триоли разрешены в 0.4; произвольные tuplets, глобальный swing и microtiming вне объёма.
2. Единая Pattern v2 и целые ticks, PPQ960. Draft v1, импорт Pattern v1 с миграцией. Ноты не меняются при переключении сетки. Прямые/триольные позиции смешиваются; grid=8T/16T — явные строки.
3. Сверху вниз: крэш 2, крэш 1, райд, хэт, том 1, том 2, том 3, малый, бочка. Новое требование 27.10 заменило прежний порядок томов; ID/звуки/GM50/47/43 неизменны.
4. Собственные синтезированные WAV, CC0. Это проверяет механику, но не заменяет акустический банк и velocity layers. Чужие звуки без разрешения на распространение не включаются.
5. Нативный Web Audio вместо Tone.js: AudioContext создаётся только по жесту, один Scheduler, фон приводит к паузе. Шаг scheduler40ticks для точного пересечения прямых/триольных позиций; poll25ms/lookahead75ms. Реальный iPhone-тайминг ещё не измерен.
6. Аудио iPhone: запрос доступного Audio Session playback; браузер без API работает стандартно. Восстановление пересоздаёт контекст и играет тест, resume имеет таймаут 3 секунды. Слышимость и положение переключателя не определяются сайтом.
7. Каждое касание — один переход пусто→80→35→пусто, одна операция истории. Акцент при первом касании становится обычным. Long-press/contextmenu не открывает динамику. Импортированные velocity/акценты сохраняются в модели.
8. Явная команда «Изменить / перенести удар» даёт динамику, акцент, удаление, перенос на той же дорожке. Mouse drag сохранён. Scroll и pointercancel не меняют события.
9. Мобильные названия — полные, над каждым рядом, закреплены слева при горизонтальной прокрутке до 760px. Боковой колонки нет. На desktop имена слева. Выигрыш 56px ширины при добавлении 28px высоты на ряд; на 390px сетка 1/8 показывает 7 полных клеток вместо 6 у промежуточного варианта.
10. Транспорт: только иконки Play/Pause, aria-label/aria-busy сохранены. Тот же usePlayback обслуживает верхнюю и закреплённую кнопки. «В начало» удалена по прямому запросу пользователя вместе с onReset виджета, её CSS и неиспользуемой иконкой stop. Внутренний reset нужен созданию/импорту/примеру.

| Состояние        | Действие кнопки                             |
| ---------------- | ------------------------------------------- |
| Остановлено      | Play продолжает сохранённую позицию         |
| Игра             | Pause глушит звук и сохраняет позицию       |
| Подготовка       | Кнопка заблокирована, aria-busy=true        |
| Ошибка           | Play повторяет подготовку; сообщение рядом  |
| Предпросмотр     | Тот же транспорт играет производный вариант |
| Фон/сворачивание | Автопауза; возврат без автозапуска          |

11. Темп 40–240: −/+ по 1BPM, удержание 450/100ms; барабан с отдельным значением и подтверждением. Подробности — MOBILE-TEMPO-UX.md.
    12.33 брейка и 15 грувов — оригинальные учебные адаптации с точными событиями/источниками, не транскрипции и не доказательство популярности. Каталог брейков — основной путь; произвольный участок/генератор — дополнительный. Недостающие инструменты не фильтруются, добавляются только явно. Предпросмотр не сохраняется; применение одной командой Undo.
12. Обычный swing подтверждён пользователем как long/short, обратный — short/long. Вариант обратного обозначен учебным, а не джазовым стандартом. Отдельные события ride/малого/бочки; глобальной свинговой обработки нет. Человеческая слуховая приёмка открыта.
13. Черновик локальный, после reload/закрытия, без сохранения Undo. Повреждённые данные не перезаписываются молча. JSON — резервная копия; откат на 0.3 не поддерживает новые триольные данные.
14. Проверки и бюджеты не ослаблять. Реальный Safari/iPhone и музыкальную оценку не объявлять выполненными по Chromium/WebKit. Нотация, другие размеры, акустический банк, MP3/MusicXML не реализованы и остаются отдельными задачами.
15. Версии приложения — SemVer, аннотированные теги и GitHub Releases с CHANGELOG. Кандидаты используют суффикс rc.N; после принятия подготовлена стабильная 0.4.0. Номер приложения независим от схем данных. Снимки интерфейса обновляются при изменении UI/версии; version:check контролирует package/lockfile/changelog/manifest.
16. Pages — только проверенный main-артефакт после зелёного CI при PAGES_ENABLED=true. Создание тега/prerelease не заменяет слияние и не запускает CD. Пользователь принял изменения и явно разрешил слияние; PR #18 объединён в main.
