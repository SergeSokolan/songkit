# Решения

1. Версия 0.2 использует 4/4, 1–4 такта, три базовые и шесть добавляемых дорожек. В 0.2 триоли/свинг/микротайминг были отложены; разрешение триолей в 0.4 описано в решении 16. Глобальный свинг и микротайминг остаются вне объёма.
2. До выбора лицензированного акустического банка используются оригинальные синтезированные WAV из scripts/generate-sounds.mjs. Это проверяет механику, но не качество обещанной рок-установки. Тихие/сильные удары пока меняют gain, без velocity layers. Лицензия собственных звуков CC0, см. docs/SOUND-LICENSE.md.
3. Используется нативный Web Audio: AudioContext создаётся только по жесту пользователя. Tone.js удалён после зависания WebKit на этапе загрузки; библиотека использовалась лишь как источник контекста. Небольшой scheduler поверх AudioContext отдельно тестируется и читает одну модель партии. Нужды в AudioWorklet на этом этапе не выявлено.
4. Смена сетки не изменяет события. Скрытые мелкие удары отмечены счётчиком. 32-е доступны прокруткой с достаточно крупными клетками; отдельное увеличение одной доли предстоит оценить на iPhone после прототипа.
5. Черновик сохраняется после reload/закрытия для защиты от выгрузки вкладки iOS. Удаление явное. Undo хранится только в текущей сессии. Перенос файлов — JSON, не хранение на сервере.
6. Перенос пальцем выполнен через меню «Перенести» и выбор клетки, чтобы не конфликтовать с горизонтальной прокруткой. Drag мышью поддерживается.
7. Публикация на Pages разрешена пользователем; только после зелёного CI. CI/CD подготовлен в одном workflow: production deploy зависит от успешного verify и использует проверенный артефакт.
8. Нотация, другие размеры, акустический банк, MP3/MusicXML не входят в этап B. Не выдавать их за готовые функции.

9. По запросу пользователя 2026-10-25 добавлены три тома, райд и два крэша. Дорожки расположены по высоте, бочка внизу. Для совместимости сохранён импорт v1, новый JSON содержит schemaVersion 2 и instruments.
10. Красный CI исходного прототипа был связан с зависанием WebKit при загрузке аудиобиблиотеки. Нативный AudioContext создаётся только по жесту; регрессионная проверка запрещает создание контекста при загрузке страницы. Исправление подтверждено зелёным GitHub run 40216234860.

11. Версия 0.2.1: iPhone может заглушать ambient Web Audio физическим переключателем. По жесту запрашивается playback через опциональный Audio Session API; без поддержки API сохраняется стандартное поведение и понятная подсказка. Положение переключателя не определяется сайтом. Нет молчаливого audio-loop, записи микрофона или принудительного автоматического воспроизведения.
12. Восстановление звука явно пересоздаёт контекст и запускает тест бочки/малого/хэта, не меняя партию. Resume имеет таймаут 3 секунды; поздний результат старого запуска не сбрасывает уже возобновлённый контекст и не перезаписывает новые буферы. Остановка и уход в фон прекращают также тестовые/предпрослушиваемые звуки. При unmount контекст закрывается.

13. По задачам #6/#7 версия 0.3.0 добавляет брейки и мобильный темп. Библиотека из шести оригинальных CC0-шаблонов и детерминированный локальный генератор описаны в FILLS.md. Предпросмотр не сохраняется; выбор аудио фиксируется при входе в участок одним Scheduler. Применение — обычные события v2 одной командой истории.
14. Темп: −/+ по одному BPM, удержание 450/100 мс; барабан в modal dialog с отдельным значением и подтверждением. Сравнение вариантов и ограничения ручной проверки — MOBILE-TEMPO-UX.md. Новых зависимостей нет.

15. 2026-10-27, v0.4: новое требование заменяет порядок томов от 25.10: сверху вниз tom1/tom2/tom3; ID, звуки и GM неизменны.
16. Триоли разрешены в данном объёме. Grid использует явные 8T/16T; события не мигрируют. Scheduler обходит 40-tick базу для точного объединения сеток; view/currentPosition теперь имеют это разрешение вместо прежних 120. Audio lookahead остаётся 75 мс, poll 25 мс.
17. Цикл касаний выбран из рабочего предложения бэклога: обычный→тихий→пусто, без зависимости от тайм-аута double-click. Акценты доступны через явный редактор и импорт. Удержание больше не запускает панель.
18. Транспорт: квадрат выглядит как Stop и требует объяснения; перенос сброса только в меню ухудшает доступ к повтору; оставляем видимую вторичную «В начало» с возвратной иконкой. Главные Играть/Пауза дублируются у сетки через тот же usePlayback.

| Состояние              | Играть/Пауза              | В начало                         |
| ---------------------- | ------------------------- | -------------------------------- |
| Остановлено в начале   | запуск с 0                | остаться в 0                     |
| Остановлено с середины | продолжить                | позиция 0, без запуска           |
| Игра                   | пауза с позицией          | заглушить, позиция 0             |
| Подготовка             | кнопки Play заблокированы | отменить подготовку, 0           |
| Ошибка                 | повторить Play            | остановить, 0                    |
| Предпросмотр           | играть/пауза той же фразы | начало всей фразы                |
| Уход в фон             | автоматическая пауза      | при возврате только явный запуск |

Ноты и история транспортом не меняются. Внутренний reset создания/импорта сохранён.

19. Брейки и грувы — оригинальные учебные адаптации, с точными событиями и источниками семейств. Каталог не фильтрует нужные инструменты и не округляет триоли. Старый генератор доступен отдельно. Обычный и обратный свинг согласованы пользователем как long/short и short/long; глобальный swing не вводится. Музыкальная приёмка человеком пока открыта.

20. Мобильные подписи по следующему запросу пользователя27.10.2026 перенесены над каждым рядом, боковая колонка скрыта до760px. Полные имена закреплены слева при горизонтальной прокрутке. Выигрыш56px ширины за счёт28px дополнительной высоты на дорожку. На390px видно7 полных клеток вместо6 в прежнем компактном варианте; desktop сохраняет подписи слева.
