# Скриншоты интерфейса

Текущие снимки — **0.4.0**, Chromium/Playwright, CSS viewports, сетка 1/8, масштаб 100%. Это не снимки реального iPhone. Номер версии, отпечаток исходного кода и геометрия записаны в [manifest.json](manifest.json).

- [Телефон 360](after-360.png), [390](after-390.png), [430](after-430.png): базовые дорожки, названия над рядами, кнопки воспроизведения только с иконками, без «В начало».
- [Телефон 390, все 9 дорожек](full-kit-390.png): порядок томов 1/2/3.
- [Desktop1280](desktop-1280.png): подписи слева.
- `before-360/390/430.png` — исторический baseline0.3.0, не текущий интерфейс. Сохранён только для сравнения; удалённые в дальнейшем элементы на этих снимках ожидаемы.

После правок интерфейса или номера версии:

```powershell
$env:BASE_PATH = '/songkit/'
npm run build
npm run docs:screenshots
npm run format
npm run version:check
```

Скрипт запускает временный локальный preview, делает снимки из чистых браузерных контекстов и записывает измерения. Нужен установленный Playwright Chromium; его путь можно задать через PLAYWRIGHT_BROWSERS_PATH. По умолчанию порт 4178, переопределение SONGKIT_DOCS_PORT.

Перед коммитом обязательно просмотреть PNG: автоматическое совпадение версии не доказывает корректность внешнего вида. Исторические baseline не перезаписывать при обычном обновлении.
