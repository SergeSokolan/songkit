# Передача работы по SongKit

Актуально для 0.4.0-rc.1,2026-10-27. Первоначальное задание A/B выполнено. Текущие правила: AGENTS.md, SPEC.md, ARCHITECTURE.md, DECISIONS.md. Сначала проверить status/ветку/remote; сохранять пользовательские изменения.

Работа версии 0.4 находится в PR#18. В main опубликована 0.3.0. Не выдавать RC/ветку за production; для слияния PR ранее запрошено отдельное подтверждение, пока оно не получено. Теги/релизы оформлять по RELEASING.md, опубликованные теги не перемещать.

Реализованы триоли, UX мобильной сетки, цикл касаний, иконки воспроизведения без сброса,33 брейка и 15 грувов. Актуальные скриншоты — docs/screenshots/README.md. Подробности и оставшиеся критерии — BACKLOG-2026-10-27.md.

Далее: ручная приёмка iPhone13/Safari/PWA с записью iOS, устройства, версии и SHA; прослушивание шаблонов на медленном/рабочем темпе. Не отмечать эти пункты выполненными по автоматическим тестам. Остальные размеры, нотация, акустический банк, MP3/MusicXML — только отдельными задачами. Подбор аккордов, аналитика и облачные партии вне объёма.

Перед сдачей npm run check, production BASE_PATH=/songkit/, npm run test:e2e, npm run format:check. При изменении UI/версии обновлять документацию, снимки через npm run docs:screenshots и CHANGELOG; сверять версию package/lockfile/manifest.
