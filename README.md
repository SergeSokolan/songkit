# SongKit

Барабанная мастерская для iPhone и компьютера. Первый прототип: 4/4, 1–4 такта, бочка/малый/хэт и добавляемые томы 1–3, райд, крэши 1–2, сетка до 1/32, тихие удары/акценты, undo/redo, воспроизведение с правками, локальный черновик, JSON и MIDI. Без аккаунтов и сервера данных.

## Запуск на Windows

Установите Node.js версии из `.node-version` (24.22.1), затем в PowerShell из папки проекта:

```powershell
npm ci
npm run dev
```

Откройте адрес из терминала. Для проверки production PWA и офлайна:

```powershell
$env:BASE_PATH = '/songkit/'
npm run build
npm run preview
```

Откройте `http://localhost:4173/songkit/`. Офлайн-режим работает в production на HTTPS или localhost. Обычный HTTP-адрес компьютера в локальной сети на iPhone не обеспечивает Service Worker. Для настоящей проверки iPhone используйте HTTPS-размещение.

## Управление

- Касания клетки: пусто → обычный → тихий → пусто. Удержание не открывает панель. Для акцента выберите «Изменить / перенести удар», затем клетку.
- Перенос: «Изменить / перенести удар» → существующий удар → «Перенести удар» → новое место на той же дорожке. На компьютере также работает перетаскивание мышью.
- Сетка меняет привязку, сохраняя все удары. Цифра внизу клетки обозначает удары между видимыми делениями. Выберите подходящую прямую (до 1/32) или триольную (1/8T, 1/16T) сетку, чтобы увидеть их.
- Несколько тактов играют по кругу, выбранный такт редактируется независимо от звучащего.
- Черновик сохраняется локально, включая обновление страницы и закрытие. При возвращении звук запускается кнопкой. Экспорт проекта — отдельная резервная копия; очистка данных браузера удаляет черновик.
- «Новая партия» очищает рисунок с подтверждением. Undo возвращает ноты, пока сессия открыта. История undo не сохраняется между запусками.
- Тихие удары и акценты передаются в MIDI как velocity. Порядок сверху вниз: крэш 2, крэш 1, райд, хэт, том 1, том 2, том 3, малый, бочка. Базовые дорожки всегда видны; другие добавляются через «Добавить инструмент» и сохраняются в проекте. Старые файлы v1 автоматически переводятся в v2. Сейчас звуки синтезированные; акустический рок-банк предстоит выбрать с лицензией на распространение семплов.

- Темп: кнопки −/+ с удержанием; BPM открывает барабан выбора с «Готово» и «Отмена». Изменение на ходу вступает на ближайшей доле.
- «Брейки»: выберите участок и дорожки, прослушайте библиотеку rock/pop/funk или локальные предложения, затем примените. Тома добавляются с явным разрешением. Вся замена отменяется одним Undo. Подробнее: [брейки](docs/FILLS.md), [мобильный темп](docs/MOBILE-TEMPO-UX.md).

## Проверки

```powershell
npm run check
npx playwright install chromium webkit
npm run test:e2e
```

Для E2E сначала соберите production с `BASE_PATH=/songkit/`, как выше. `check` выполняет форматирование, lint, типы, FSD/циклы, тесты с coverage, сборку и ограничения размера. Подробнее: `docs/TESTING.md`.

## GitHub и публикация

Репозиторий: https://github.com/SergeSokolan/songkit. Основная ветка `main`; изменения проходят через PR. Workflow `.github/workflows/ci.yml` проверяет PR и push в main; это исключает дублирование одного запуска на PR и push рабочей ветки.

Публикация разрешена пользователем. Настройки хостинга: Settings → Pages → Source: GitHub Actions; Settings → Secrets and variables → Actions → Variables: `PAGES_ENABLED=true`. После успешных проверок push в main публикует тот же build-артефакт. Адрес публикации: https://sergesokolan.github.io/songkit/. Перед объявлением готовности необходимо подтвердить успешный deploy и HTTP-проверку.

Настройте защиту main с обязательным job `verify`, PR и запретом force push. Публичное приложение не получает доступа к GitHub-учётным данным. Workflow не использует пользовательские токены.

## Звук на iPhone / PWA

Версия 0.2.1 запрашивает `navigator.audioSession.type = 'playback'` прямо в пользовательском жесте перед созданием/возобновлением AudioContext. Это обозначает основное музыкальное воспроизведение вместо стандартного ambient-режима Web Audio. API экспериментальный: браузеры без поддержки продолжают использовать обычный Web Audio.

На iPhone рядом с управлением есть подсказка о беззвучном режиме и громкости медиа. Сайт не может определить положение физического переключателя или факт того, что человек слышит звук. «Нет звука?» → «Восстановить звук» пересоздаёт аудиоконтекст и запускает короткий тест без изменения нот. Проблемный resume ограничен тремя секундами, после чего интерфейс предлагает восстановление. Для звонков/сворачивания сохраняется пауза без автоматического запуска.

После публикации обновления полностью закройте PWA и снова откройте её с интернетом; при необходимости закройте также вкладки SongKit в браузерах. Новая версия видна внизу возле GitHub. Не удаляйте данные браузера для обычного обновления: локальный черновик хранится там.

Спецификация: https://www.w3.org/TR/audio-session/. Особенности iOS: https://bugs.webkit.org/show_bug.cgi?id=237322 и https://bugs.webkit.org/show_bug.cgi?id=291892. Реальный беззвучный режим проверяется на устройстве; браузерная эмуляция не заменяет эту проверку.
